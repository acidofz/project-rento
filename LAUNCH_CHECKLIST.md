## Эндпоинты для мониторинга

| URL | Назначение |
|-----|------------|
| `GET /ping` | Встроенный в Reflex «жив ли процесс» (Railway healthcheck). |
| `GET /_health` | Встроенный JSON Reflex (БД/Redis Reflex, не Supabase). |
| `GET /ready` | Проверка доступности Supabase (`listings`, limit 1). Если env не задан — `200` с `not_configured`. |
| `GET /health` | Человекочитаемая страница в браузере. |

Скрипт: `scripts/smoke_deploy.sh` (переменная `BASE_URL`).

---

## P0 — блокеры (без этого No-Go)

- [ ] Прод-окружение Supabase отделено от разработки; применён актуальный `supabase_schema.sql`.
- [ ] В проде заданы переменные: `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, `ADMIN_USER_IDS`.
- [ ] Деплой с публичным URL и HTTPS; healthcheck платформы указывает на **`/ping`**.
- [ ] `GET /ping` и страница **`/health`** открываются с прод-домена.
- [ ] `GET /ready` на проде возвращает `supabase: ok` (если проект уже на реальной БД).
- [ ] Регистрация, вход, публикация объявления (по желанию с фото) работают под реальным пользователем.
- [ ] RLS проверен сценариями: нельзя менять чужие объявления; публичное чтение ленты работает.
- [ ] Админ-панель доступна только админам из `ADMIN_USER_IDS`; блокировка и удаление проверены.
- [ ] Бэкапы Supabase включены; есть понятный план восстановления (хотя бы один успешный тест restore).

---

## P1 — сильно желательно до открытия

- [ ] Логи деплоя и алерты при падении сервиса или росте 5xx.
- [ ] Мобильная проверка основных экранов: лента, карточка, создание, чат, карта.
- [ ] Тексты **`/terms`** и **`/privacy`** выверены под прод (желательно с юристом).
- [ ] `robots.txt` и `sitemap.xml` открываются с прод-домена.
- [ ] Политика премиум-размещения понятна пользователям (сейчас без оплаты — см. правила на сайте).

---

## P2 — можно сразу после запуска

- [ ] Sentry или аналог для фронта/бэка.
- [ ] Продуктовая аналитика (воронка: регистрация → объявление → чат).
- [ ] Уведомления о новых сообщениях (email / внешний сервис).
- [ ] Оплата премиума и лимиты по тарифам.
- [ ] Жалобы на объявления и расширенная модерация.

---

## Smoke-тест (15–20 минут)

Выполните локально или с прод-URL:

```bash
BASE_URL=https://ваш-домен uv run bash scripts/smoke_deploy.sh
```

Дополнительно вручную:

- [ ] Два разных аккаунта: чат между ними.
- [ ] Избранное: добавить и убрать.
- [ ] Премиум: включить у объявления — выше в ленте при той же сортировке.

---

## Критерий Go / No-Go

- **GO:** все пункты P0 выполнены.
- **NO-Go:** любой пункт P0 не выполнен.
- **GO с риском:** P0 выполнен, часть P1 нет — только с явным списком рисков и сроком закрытия.
